Privacy policy

Paper & Panic · last updated 23 November 2026

Paper & Panic is a channel that publishes short history videos. Its creator uses a small private tool, also called Paper and Panic, to read the channel's own YouTube statistics and to upload the channel's own videos. This page explains what that tool does with Google account data.

Who can use the tool

Only the channel's owner. It is not offered to the public, and no other person's account is ever connected to it.

What data it accesses

When the owner signs in with Google, the tool asks for these permissions:

  • View your YouTube account (youtube.readonly): the channel's name, subscriber count and list of videos.
  • View YouTube Analytics reports (yt-analytics.readonly): views, watch time, likes, shares and subscribers gained for the channel's own videos.
  • Manage your YouTube videos (youtube.upload): to upload videos the owner has scheduled. The tool cannot edit or delete videos.

How the data is used and stored

  • The statistics are saved only on the owner's own computer, to show a progress dashboard and decide which videos to make next.
  • The sign-in token is stored only on that computer, in a file that only the owner's user account can read.
  • No data is sold, shared with anyone, used for advertising, or sent to any server other than Google's own APIs.
  • No data about viewers of the videos is collected beyond the totals YouTube Analytics reports to every channel owner.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the tool's access at any time at myaccount.google.com/permissions, and delete the stored statistics from their computer.

This website

This site is a static page hosted on GitHub Pages. It uses no cookies, no analytics and no forms. GitHub may log visits as described in the GitHub Privacy Statement.

Contact

Questions about this policy can be sent through the Paper & Panic YouTube channel.
